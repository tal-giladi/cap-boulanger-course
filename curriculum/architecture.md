# Course architecture and lesson inventory

This inventory is fixed: lesson counts, ids, files and running numbers must not change once a module
is written (paths are stable ids). Titles may be refined by the module writer; the sidebar uses the
lesson's H1. Competency codes: see `competency-map.md`.

Progression of practice: measuring and simple doughs (1–7) → pain courant (8) → tradition (9) →
several breads (10) → viennoiserie (11–12) → several products at once (14) → full production day (22).

Each module also has: `assessments/module-NN-quiz.md` + `.quiz.yaml` (8–10 questions) and a project
brief `projects/mNN-<slug>.md` (the module's larger practical piece).
