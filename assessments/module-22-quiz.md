# Module 22 Quiz: EP2 Practice and Production Day

This mock round checks the production-test skills you can practise on paper, using the documents of a production day: a marking grid, a technical sheet to calculate, a temperature log, a list of dough chains for an organigramme, a home oven plan, a cream cooling log, an examiner's notes on semi-finished products, a malfunction report and a readiness plan. It has 10 multiple-choice scenario questions; the pass mark is 70%. Suggested time: 30 minutes with a calculator, without notes. The exam's own rules are in [The CAP Boulanger Exam](../references/cap-exam.md).
