# CV and Cover Letter (CV et Lettre de Motivation)

A one-page French CV and a one-page letter for a bakery job. There is no legal model; employers expect a short, clear document with facts and numbers. You do not have to give a photo, your age, family situation, religion or health. Method and examples are in lesson [20.3](../lessons/module-20/lesson-03.md).

## CV (one page)

| Section | Entry |
|---|---|
| En-tête: name, phone, e-mail, town; the job you want (for example "Ouvrier boulanger — CAP Boulanger en préparation") | |
| Expérience professionnelle (most recent first): dates, bakery, town, tasks with numbers | |
| Formation: CAP preparation, training, placements, hygiene training | |
| Compétences: products you can make, machines you have used, hygiene and allergen rules | |
| Langues, informations: languages, driving licence, availability (nights, weekends) | |

## Cover letter (one page, formal French)

| Part | Entry |
|---|---|
| Your name and address; the employer's name and address (spelt right); town and date | |
| Objet: the job and the advert | |
| Madame, Monsieur, | |
| **Vous**: why this bakery (its products, its reputation, the advert) | |
| **Moi**: what I can bring (skills and facts from the CV, not a copy of it) | |
| **Nous**: what we can do together (availability, request for an interview or a trial morning) | |
| Formule de politesse and signature | |

Check before sending: one page each, no spelling mistakes, numbers in the experience, the bakery named in the letter.
