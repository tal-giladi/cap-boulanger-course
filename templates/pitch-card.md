# Pitch Card (Fiche Argumentaire)

One card per product for the sales staff. A pitch card is not advertising: every block comes from a document the bakery holds, written in the Source column, so the seller can repeat it without risk. Method and honest names are in lesson [19.2](../lessons/module-19/lesson-02.md).

| Block | Entry | Source (document) |
|---|---|---|
| 1 Name (as on the shelf label; legal names checked, lesson [09.1](../lessons/module-09/lesson-01.md)) | | shelf label, technical sheet |
| 2 Composition and method | | [technical sheet](production-sheet.md) |
| 3 Taste and texture (descriptors, not adjectives) | | [tasting sheet](tasting-sheet.md) |
| 4 Goes with | | tasting, house practice |
| 5 Keeps (how, how long, freezing) | | storage rules (lesson [07.5](../lessons/module-07/lesson-05.md)) |
| 6 Allergens | | [allergen table](allergen-table.md) |
| 7 Seller's sentence (blocks 1-5, under 30 words) | | blocks 1-5 |

Words to avoid unless a document proves them: tradition, maison, au levain, source de fibres, sans gluten, health promises.
