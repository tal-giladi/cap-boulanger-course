# Temperature Log

Dough temperature controls fermentation speed. This log records the base-temperature calculation and checks it against what you measured.

## Calculation

| Item | °C |
|---|---|
| Target dough temperature | |
| Base temperature = target × number of temperature factors | |
| Flour temperature | |
| Room (fournil) temperature | |
| Pre-ferment temperature (if counted) | |
| Friction factor (mixing heat × number of factors) | |
| **Water temperature = base − (flour + room + pre-ferment) − friction** | |

If the water must be colder than your tap water, replace part of it with ice (lesson 05.3).
