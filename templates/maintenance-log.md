# Maintenance Log (Cahier d'Entretien)

A sheet kept beside the scale or the machine and filled in at a fixed rhythm. It turns checks into evidence; a failed check holds the equipment back and is reported (lesson [13.6](../lessons/module-13/lesson-06.md)).

| Date | Item | Check | Result | Pass / fail | Action taken | Initials |
|---|---|---|---|---|---|---|
| | Scale | known weight (or sealed 1 L bottle of water, about 1,000 g) | ___ g | | | |
| | Probe thermometer | iced water | ___ °C | | | |
| | Oven thermometer vs display | | ___ °C / ___ °C | | | |
| | Guards and emergency stops | machine stops | | | | |
| | | | | | | |

A failed check: stop using the item for weighing or measuring, tag it, tell the manager and write a [non-conformity report](non-conformity-report.md). Write the repair or recalibration as a new line with its date.
